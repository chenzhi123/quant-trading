核心功能

六大模块协同运作，从数据获取到信号生成、风控监控、回测验证，形成完整交易闭环。

实时行情接入

通过方正证券 XtQuant API 获取沪深300ETF实时报价、期权链全量数据和iVIX波动率指数，盘中每30秒自动刷新。

多维指标引擎

计算近1年iVIX滚动分位数、价格分位数和MACD(12,26,9)柱状图。精确判定"翻红且放大"状态，消除人为主观判断。

智能信号生成

BUY_CALL: iVIX低+价格低+MACD翻红。SELL_PUT: iVIX高+价格低。自动优选平值合约，按可买总数1/10计算建议张数。

刚性风控系统

四条铁律自动监控：亏损50%强提示止损、盈利80%提示止盈、到期前3天移仓预警、保证金超60%禁止新开仓。

历史回测引擎

按相同逻辑回放近1年数据，T+1延迟成交消除未来函数，含手续费/滑点/流动性折扣。输出净值曲线、最大回撤、Calmar比率等。

可视化仪表盘

暗黑主题Web界面，实时展示分位数仪表、信号卡片、持仓盈亏、风控警告。支持一键扫描、手动录入持仓、在线回测。

策略逻辑链

从数据准备到闭环归档，全链条系统化执行。

1

数据准备

获取沪深300ETF实时/日线行情、iVIX波动率指数实时点位与近1年历史序列、期权链全量合约报价。

2

指标计算

滚动252日iVIX分位数、价格分位数、MACD(12,26,9)柱状图翻红放大检测。判定当前点位在历史区间中的位置。

3

信号扫描

iVIX分位 ≤ 10% + 价格分位 ≤ 10% + MACD翻红 → BUY_CALL
iVIX分位 ≥ 90% + 价格分位 ≤ 10% → SELL_PUT
同类型信号3个交易日冷却期，避免重复触发。

4

合约优选

按到期日(25-35天)、流动性(成交量≥500, 持仓量≥1000, 价差≤2tick)、Delta接近0.5(平值)、成交量排序，选出最优合约。

5

仓位计算 & 信号推送

建议张数 = 总可买(卖)张数 × 1/10。生成含建议价、止损价、止盈价的结构化信号，推送至仪表盘等待确认。

6

风控监控 & 闭环

持仓期间每30秒检查：止损(-50%)、止盈(+80%)、到期预警(T-3)、保证金熔断(60%)。所有操作仅提示，不自动下单。

交易规则速查

所有阈值均可在 config/strategy.yaml 中自定义，以下为默认值。

规则条件动作
买入 Call iVIX分位≤10% + 价格分位≤10% + MACD翻红放大 买入次月平值看涨期权
卖出 Put iVIX分位≥90% + 价格分位≤10% 卖出次月平值/轻虚看跌期权
止损 盈亏% ≤ -50% 强制提示平仓
止盈 盈亏% ≥ +80% 强制提示锁定利润
到期预警 距到期 ≤ 3天 提示移仓或平仓
保证金熔断 保证金占净资产 ≥ 60% 禁止新开卖仓
